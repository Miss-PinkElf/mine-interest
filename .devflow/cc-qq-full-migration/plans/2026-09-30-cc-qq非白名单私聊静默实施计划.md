## 目标

私聊未获授权时，插件不发任何 QQ 文本，也不进代理。和私聊关闭时一样静默。

## 行为

- 私聊关闭：继续范围外静默。
- 私聊开启，发送者不在 `private_user_ids`，也不是 owner / 管理员：改为范围外（Out of Scope），不回复。
- 群聊 @ 后不在白名单：仍回复「当前 QQ 账号未获此会话授权，请联系插件管理员。」
- 私聊配置无效或缺少工作目录：仍回复原提示，方便管理员排查。

## 实施顺序

1. 用失败测试锁住：私聊开启但发送者不在名单 → `allowed` 为假，原因是 `REASON_OUT_OF_SCOPE`；群聊未授权原因仍是 `REASON_NOT_ALLOWED`。
2. 在 `policy.py` 的成员白名单判断里，私聊走范围外，群聊保持未授权。
3. 版本升到 `0.1.15`，更新 README 与 schema 提示。
4. 跑插件单测，覆盖安装目录。

## 本轮不做 / 后续阶段

- 不改现场 `astrbot_plugin_cc_qq_config.json`。私聊开关和名单由用户在设置页恢复。
- 不改群聊未授权提示。
- 不为范围外私聊调用 `stop_event()`，避免挡住其他插件处理同一条私聊。
