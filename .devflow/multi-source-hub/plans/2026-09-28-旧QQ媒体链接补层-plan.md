# 旧 QQ 媒体链接补层（QQ Media Link Repair）

**目标：** 让 184 个旧 QQ 本地媒体链接按当前文档目录解析到已存在的文件。

**做法：** 只改 `content.md` 里的相对链接。当前路径是 `items/qq/日期/类型/标题-ID/content.md`，正确层级是 5 个 `../`。这 184 个链接都是 4 个 `../`，文件本身都在 `media/`。封套（envelope.json）不保存渲染后的链接，新渲染函数 `media_href` 已按实际存储路径计算，所以不改代码、不重下图片。

## 本轮不做

- 不把文件当成下载失败重新抓取。
- 不重写正文其余内容，不改 B 站条目，不改已经能打开的链接。
- 不把资料正文覆盖到发布目录。发布副本会去掉外链查询参数；整文件覆盖会把鉴权参数带出去。
- 不处理 B 站直连 DNS、发布间歇失败、GitHub 告警。

## 顺序

1. 备份将改动的 `content.md`。
2. 仅当原链接打不开、补一层 `../` 后落到资料目录 `media/` 内的真实文件时，才替换该链接。
3. 资料目录和发布目录分开替换，外链保持原样。
4. 复核：旧的 184 个链接全部可打开；原先可打开的本地链接数量不减少；B 站断链仍为 0。
