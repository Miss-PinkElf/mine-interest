# 全量按天迁移与直连媒体实施计划（Implementation Plan）

> 面向执行代理（For agentic workers）：按顺序以失败测试、最小实现、回归验证推进。

**目标（Goal）：** 将 QQ 与 B 站历史/新增资料迁移到按采集日组织的可读目录，并让所有媒体以 100 MiB 限制直连异步下载。

**架构（Architecture）：** 以现有 Vault（资料库）的逻辑 `item_id` 和 catalog 为不变身份，新增路径投影器、迁移器与每日索引器。媒体队列记录所有可下载节点，worker 以无代理直连写入哈希媒体库，完成后回写封套。

**技术栈（Tech Stack）：** Python 3、`unittest`、SQLite、AstrBot（机器人框架）。
