# QQ 标题分层目录迁移 Implementation Plan

**目标（Goal）：** 新旧 QQ 条目均位于 `items/qq/日期/message|forward|session/标题-ID/`，每日索引、catalog 和去重保持有效。

**结构（Architecture）：** 路径投影（Storage Path Projection）仅从封套计算，不修改逻辑 ID。复用现有迁移器的预演、冲突检查和 catalog 更新，迁移全部历史 QQ 条目；B 站路径不变。
