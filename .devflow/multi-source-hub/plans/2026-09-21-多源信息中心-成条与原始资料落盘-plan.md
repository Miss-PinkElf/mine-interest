## 核心类型（所有任务共用）

`IncomingMessage`：`platform, conversation_id, event_id, sender_id, source_time, received_at, text, nodes, is_forward, raw`

`Envelope`：align 第 4 节字段；`item_id` 逻辑串用冒号，目录用 `item_relpath` 把 `:` 换成 `/`。

QQ `item_id`：

- 单条：`qq:message:<event_id>`
- 转发：`qq:forward:<event_id>`
- 会话：`qq:session:<start_event_id>`

B 站：`bilibili:video:<bvid>` / `bilibili:article:<cvid>` / `bilibili:opus:<dyn_id>`

规则包默认：会话开始 `，，，`，结束 `。。。`，空闲 1800 秒，图片下载，视频只留链接，50 MiB，`judge.enabled=False`。

```bash
PYTHONPATH=backend/src backend/.venv/bin/python -m unittest discover -s tests -p 'test_sourcehub*.py' -v
PYTHONPATH=. backend/.venv/bin/python -m unittest discover -s tests -p 'test_bilibili*.py' -v
```
