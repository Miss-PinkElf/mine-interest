# QQ 日收集与异步媒体实施计划（Implementation Plan）

> 面向执行代理（For agentic workers）：逐项完成并以复选框记录；本计划经用户批准后才可进入实施（Apply）。

**目标（Goal）：** 让 QQ 普通消息按天持久收集并可手动或定时无重复成条，同时让图片下载脱离事件处理路径，并修复 B 站专栏/动态的 Vault Markdown。

**架构（Architecture）：** 在 `backend/src/sourcehub/` 增加日账本与媒体任务队列两个纯 Python 模块，检查插件只负责追加与调度，二者均以 Vault 下的持久文件恢复状态。B 站保留既有采集和合并逻辑，只调整 Markdown 内容节点投影与已有档案回填入口。

**技术栈（Tech Stack）：** Python 3、`unittest`、AstrBot（机器人框架）、Vault（资料库）。
