# QQ 主动收藏首期范围

## 已确认范围

- 用户选择第一阶段只满足 QQ 主动收藏：主动把需要保留的消息、图片或聊天记录投递给机器人。
- 最新入口确认：用户将内容主动转发到现有专用收藏群，群内两三个成员都是用户自己的账号；首期沿用这个习惯，机器人接收收藏群投递。此前私聊入口确认已被本次更正取代。
- 借用 AstrBot 负责机器人接入与智能体执行，信息中心独立维护原始资料和二次内容。
- 原始资料保留、仅用户可编辑；二次内容用户和模型均可编辑。
- 已收藏内容仍支持默认自动整理及开关，也能手动整理；后台可独立运行并有开关。
- 重复事件不能重复入库。主动重发产生新的投递 ID 时，如何复用原条目并保留投递来源，需要具体设计，不能假设仅靠接收事件 ID 就覆盖所有重复收藏场景。
- 使用 Git 管理修改历史的方向保持不变。

## 本轮不做 / 后续阶段

**指定群持续收集及条件筛选**明确延期。

- 对象：从日常信息源群的消息流中，按规则（Rule）、正则表达式（Regular Expression）及大语言模型（LLM）辅助判断是否收藏；不包含用户已主动筛选后投递的专用收藏群。
- 原因：用户要求先完成主动收藏一种入口，持续消息流筛选后续单独收敛。
- 后续触发：推荐主动收藏闭环验收后，由用户启动后续阶段；提前调整优先级时先更新对齐与计划。
- 后续步骤：重新对齐群范围、规则组合、模型参与方式及平台权限，再落盘计划与规格。
- 边界：首期需要接收专用收藏群的新消息；延期的是日常群消息流的自动筛选收藏，不是所有群消息接入。已收藏内容的自动整理保持不变。
- 详细记录：当前任务 `deferred/QQ指定群持续收集与规则筛选.md`。
