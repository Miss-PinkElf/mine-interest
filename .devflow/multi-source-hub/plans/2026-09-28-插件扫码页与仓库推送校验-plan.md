# 插件扫码页与仓库推送校验

**目标：** 插件卡片出现「打开插件 UI 界面」。页面能显示二维码，并能告诉用户资料仓库、告警仓库是否私有、能否用当前 SSH 推送。

**做法：**

1. 页面放在 `pages/login/index.html`。AstrBot 发现该文件后显示入口。
2. 二维码由已有扫码代码生成。页面只收到图片和状态，不收到 Cookie 或二维码密钥。
3. 仓库校验复用现有私有性检查，再对同一 SSH 地址执行 `git push --dry-run`。演练失败才算没有推送权限。演练不更新远端。
4. 资料仓库固定为现有发布地址。告警仓库读插件配置。两者相同则明确提示不能共用。
