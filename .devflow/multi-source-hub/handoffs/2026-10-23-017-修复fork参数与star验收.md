# 017：修复 `/fork` 参数错误并记录 star 验收

- 16:19:57 发送 `https://github.com/Blinue/Magpie /fork`，star 按状态跳过，fork 失败。

## 问题现象

QQ 回复：

```
GitHub 自动化：
- [成功] Blinue/Magpie：已经 star，跳过
- [失败] Blinue/Magpie：gh 执行失败：the `--remote` flag is unsupported when a repository argument is provided
```

## 问题原因

`gh repo fork <repository>` 在传入仓库参数时不允许出现 `--remote`。即使写成 `--remote=false`，该 flag 仍被视为已设置，`gh` 会在参数校验阶段直接退出。

原命令：

```
gh repo fork <repo> --clone=false --remote=false --default-branch-only
```

## 解决方案

1. 命令改为 `gh repo fork <repo> --clone=false --default-branch-only`，去掉 `--remote=false`。
2. 三份 `sourcehub` 副本同步修改，哈希一致。
3. `tests/test_github_actions.py` 的断言由「包含 `--remote=false`」改为「不包含 `--remote=false`」，并注明 gh 的限制。
4. 版本：inspector `0.6.4`、B 站插件 `0.3.5`；两个现场插件目录已覆盖，`diff -rq` 一致，`py_compile` 通过。
