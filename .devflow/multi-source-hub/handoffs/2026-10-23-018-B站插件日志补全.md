# 018：补全 B 站插件正常流程日志

## 问题现象

用户反馈在 AstrBot 平台日志中看不到 B 站插件的日志：B 站 @ 之后无法判断是否收到通知、是否开始采集、是否保存成功。此前只有发布器 `remote_private_unverified`、登录状态等 WARNING 会出现。

## 问题原因

- `Poller.scan` 收到通知后只写入 Store，不记录数量；
- `Poller.process` 采集与保存成功后完全不写日志；
- GitHub 动作日志虽然通过 `self.logger` 写入，但没有统一前缀，混在其他输出里不易筛选；
- 自动化关闭时 `_run_github` 直接返回，检测到链接也不留痕迹。

## 解决方案

1. `scan`：收到通知时记录「收到 N 条 B 站通知」。
2. `process`：每条通知记录「开始采集 B 站通知：业务｜发送者｜标题」，失败记录「采集未完成（原因）」，保存后记录「已保存 B 站条目：…」。
3. `notification_label`：标题最长 40 字（`NOTIFICATION_TITLE_LOG_MAX_CHARS`），超出截断，避免刷屏。
4. `_run_github`：所有日志统一加 `[SourceHub Bilibili]` 前缀；自动化关闭但检测到链接时记录「检测到 GitHub 链接，但 GitHub 自动化未启用，跳过」；开启时记录仓库数量与 fork 标志。
5. 版本：B 站插件 `0.3.6`；现场目录已覆盖，`diff -rq` 一致，`py_compile` 通过。
