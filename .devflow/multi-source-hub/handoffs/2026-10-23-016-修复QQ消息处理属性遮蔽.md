# 016：修复 QQ 消息处理入口属性遮蔽

## 问题现象

重载检查插件 `0.6.2` 后，QQ 群里任意消息都会报错：

```
File ".../astrbot_plugin_sourcehub_inspector/main.py", line 250, in inspect_message
    github_reply = await self._github_reply(event)
TypeError: 'bool' object is not callable
```

异常发生在 `inspect_message` 第一行，因此消息快照保存、成条入库、回复全部被跳过，**QQ 采集链路整体失效**。该错误与 `github_enabled` 开关无关。

## 问题原因

- 第 142 行：`self._github_reply = bool(self.config.get(GITHUB_REPLY_ENABLED_KEY, True))`，把配置存成实例属性。
- 第 222 行：`async def _github_reply(self, event)`，定义了同名方法。

Python 中实例属性优先于类方法，`__init__` 赋值后同名方法被遮蔽，第 250 行实际执行 `await True(event)`。

## 解决方案

1. 布尔属性改名 `self._github_reply_enabled`，同步更新第 142、243、244 行；方法名与调用点不变。
2. 新增静态守卫 `tests/test_sourcehub_plugin_names.py`：用 AST 扫描 `integrations/astrbot/*/main.py`，禁止实例属性遮蔽同名方法。已用旧部署副本验证能检出该缺陷。
3. 检查插件版本升 `0.6.3`（`metadata.yaml` 与 `constants.py`）。
4. 覆盖现场目录 `~/.astrbot/data/plugins/astrbot_plugin_sourcehub_inspector/`，`diff -rq` 一致，`py_compile` 通过。
