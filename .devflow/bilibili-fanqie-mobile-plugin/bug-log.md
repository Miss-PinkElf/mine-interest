## BUG-001 — B站导出音频音量偏小

### 问题现象

- 用户反馈：**B站已能成功下载**，**切换保存目录也正常**。
- 播放导出结果时 **声音偏小**。
- 怀疑与当前音频处理/导出方式有关。

### 问题原因（待核实，初判）

当前一体式实现常见路径：

1. `format=mp3` 选项实际多落盘为 **DASH 独立音轨 `.m4a`**（非重新转码 loudnorm）。
2. 或 `format=mp4` 时只落 **视频轨**，旁路另存音轨；若用户听的是某条未混流/低增益轨，听感会偏安静。
3. **未做** 音量标准化（loudness / gain）、**未做** 真 mp3 转码与响度提升。
4. 平台源音轨本身增益偏低也可能叠加。

具体是「源轨增益」还是「导出链路丢增益/听错文件」——**下次会话用样例文件排查**。

### 解决方案

| 状态 | 内容 |
|------|------|
| **待解决** | 下次对话优先修复（用户明确要求） |
| 建议步骤 | 1）确认用户播放的是主文件还是 `-audio` 旁路；2）对比 App 内文件与 bilibili 在线听感；3）若为 m4a 音轨：评估 MediaCodec 增益 / 文档标明「源音量」/ 后续 ffmpeg 归一；4）若 mp4 无声或极轻：检查是否只下了视频轨未带音 |
| 相关代码 | `provider-bili/BiliExporter.kt`、`BiliStreamClient.kt`、`CoreMediaFormats` |
| 非本次范围 | 完美 DASH 合并、真 mp3 转码（仍见 deferred 可降级项）；yt-dlp 引擎 |
