## 当前优先级（2026-08-07）

1. **主线：B站** — 一体式下载可用性（403 缓解、真机/模拟器验收、必要时再增强）  
2. **番茄 MVP** — 维持链接/短链 + 目录 + **用户自配正文端点**（不扩 Official-API）  
3. **延期包** — 见下表；禁止「顺手」做进当前主线

| 项 | 说明 |

## 新会话禁止偷做

- 把「Official-API / 搜书名 / 内置 token」塞进番茄 MVP  
- 把延期项当「顺手修」  
- 在 main 开发  
- 无验证证据宣称 mission 交付
