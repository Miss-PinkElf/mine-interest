## 生产 / 测试隔离

1. `test_root` 不能等于生产根 `~/.astrbot`；配置校验会拒绝。
2. 测试端口不能与生产端口重叠（生产 WebUI `6185`、OneBot `6199`；测试 WebUI `6186`、OneBot `6198`）。
3. 测试实例使用独立数据根（默认 `~/.astrbot-e2e`）与独立插件副本。
4. 两个 QQ 实例必须隔离 `NAPCAT_WORKDIR` 与端口，避免日志和配置串写。
5. 生产实例只读；任何写入、暂停、恢复都必须先得到用户明确确认。

## 备份规则

1. 修改生产配置前先生成 `.bak-<时间戳>` 备份。
2. 备份内容与改动原因写入操作记录或交接文档。
3. 不在测试流程中自动删除备份。
4. 报告与配置的保留期限由用户决定；不得自动清理。

## 进程操作

- 只停止有 PID 文件且校验属于测试实例的进程。
- 端口被未知进程占用时，只报告进程与端口，不终止；由用户决定是否处理。
- 不使用 `pkill -f` 之类的模糊匹配终止进程。
- 非 attach 模式结束只停止由本次执行启动的实例；`--keep-running` 时保留。

## 敏感信息

- `config.local.json`、`reports/`、`vendor` 生成物中的本地路径不提交。
- QQ 号、OneBot token、WebUI 密码、LLM key 不得出现在报告、日志截图或提交信息中。
- 报告默认脱敏；不要关闭脱敏，除非用户明确要求并知晓风险。
- `report.json` 可能已脱敏；重新生成不会恢复原文。

## 用户确认清单

| 动作 | 是否必须确认 |
| --- | --- |
| 启动测试实例 | 否（属于测试侧） |
| 停止自有测试实例 | 否 |
| 暂停/恢复生产 AstrBot | 是 |
| 修改生产配置 | 是 |
| 终止未知进程 | 是 |
| 删除数据/日志/报告 | 是 |
| 关闭报告脱敏 | 是 |
| 自动扫码登录 | 禁止 |

## 报告与归档

- 报告保留在本地 suite 目录，不入库。
- 分享报告前再次检查是否包含 QQ 号、群号、token、内网地址。
- 需要长期留存的结论写入 mission 的 `state.md` 或交接文档，而不是只留在聊天里。
