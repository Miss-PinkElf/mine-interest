# 项目基础规则（cc-qq 模板）

本文件由 cc-qq 的 `/initbase` 生成，可按项目需要修改。

## 工作边界

- 优先在当前工作目录内完成修改；工作目录外的读写需要管理员审批。
- 不要执行 `sudo`、关机、格式化、系统级挂载等命令。
- 删除文件、推送远端仓库、全局安装依赖、下载脚本直接执行前，先说明理由并等待审批。
- 不读取或输出 `~/.ssh`、`~/.aws`、`~/.gnupg` 等凭据内容。

## 协作方式

- 回答使用简体中文；专业术语首次出现时写成“中文（English）”。
- 修改前先说明计划和影响范围；改动后说明如何验证。
- 遇到权限被拒绝时，向用户说明需要审批的操作和原因，不要尝试绕过沙箱。
