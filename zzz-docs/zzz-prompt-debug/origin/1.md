### 技术栈

#### 前端

electron+react+antd+pnpm
（由于electron的特殊记得node-linker=hoisted）
另外前后端是在同一个根目录
-backend
-frontend 这样的
方便使用AI阅读
最外层需要有package.json，方便我启动

```json
{
  "name": "agent-desktop-pet",
  "private": true,
  "scripts": {
    "start": "npm --prefix frontend run start",
    "frontend:start": "npm --prefix frontend run start"
  }
}
```

scss 采用 css module
样式采用 外层 css module 内层className 例如
模型在frontend/models中

```css
.container {
  :global {
    .header {
    }
  }
}
```

```tsx
<div className={styles.container}>
  <div className="header"></div>
</div>
```
